# Optimize VMD parameters using the Golden Cat Algorithm, allowing for six fitness functions to be switched at will. Minimize Envelope Entropy, Sample Entropy, Information Entropy, Arrangement Entropy, Arrangement Entropy/Mutual Information Entropy, and Envelope Spectrum Peak Factor

This program utilizes the VMD function provided by MATLAB itself, so it must be run in MATLAB 2020 and above. Only MATLAB versions 2020 and above come with the VMD function!
